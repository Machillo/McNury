# Plan inicial de Mac Nury

## Objetivo

Simplificar la recepción de pedidos para recoger y ofrecer a la familia una vista confiable de ventas, caja, inventario, costos y ganancia estimada.

## Roles

- **Encargada:** acepta pedidos, cambia estados, registra ventas rápidas, agota productos y cierra caja.
- **Ayudante:** registra compras, ajusta inventario y ayuda con pedidos.
- **Administrador:** configura menú, recetas, costos, usuarios, pagos y reportes.

## Entregas

1. Demo visual y flujo local.
2. Pedidos persistentes y autenticación.
3. Ventas rápidas para local, teléfono y WhatsApp.
4. Inventario por ingredientes y recetas.
5. Compras, gastos y cierre de caja.
6. Costos y precios recomendados.
7. Notificaciones en tiempo real.
8. Tarjetas, Apple Pay y Google Pay mediante una pasarela compatible.
9. Publicación Android, iOS y web.

## Principios de uso

- Botones grandes y lenguaje cotidiano.
- Las tareas diarias deben requerir pocos toques.
- La configuración delicada queda reservada al administrador.
- Ningún número de tarjeta se almacena en Mac Nury.
- Las ventas de todos los canales deben registrarse para que el cierre sea correcto.
